The question nobody can answer yet

    
2026 made software agent-native: agents run shells, edit files, hit APIs, ship to prod. Frameworks gave them memory, harnesses, tools. Nobody gave them a flight recorder. So when something breaks, you get a story — not evidence.

    

      
📼
Record anything
agentbox wrap -- anything. Wraps the process, captures stdout/stderr/stdin, classifies tool calls, file ops, shell commands, URLs. Zero code changes in the wrapped program.

      
🔐
Tamper-evident tape
Every event is sha256-chained, genesis to tip. Edit one character and agentbox verify pins the exact forged event. Logs are opinions; chains are evidence.

      
🧾
Receipts, not dumps
One page a human can scan in five seconds: tool calls, files touched, deletions flagged, URLs hit, and the deadpan metric — humans consulted: 0.

      
🎬
Replay like footage
Interactive TUI scrubber with a timeline of markers. Play at 1–64×, jump to the exact moment, step event by event. Headless mode renders frames for CI and GIFs.

      
✂️
Shareable clips
Export any time range as one self-contained HTML file. Drop it into a PR, an incident review, or the group chat. Works offline, forever.

      
🤖
GitHub-native
Receipts as markdown in PR comments via the bundled Action. Sessions are plain JSONL in your repo — commit them, grep them, own them.

# strap a black box to anything
agentbox wrap --name prod-deploy \
  -- node agent.js "ship the release"

# read the tape
agentbox receipt      # one-page summary
agentbox replay      # scrub the footage
agentbox verify      # chain intact?
agentbox clip        # share a moment

        

        
The tape is plain JSONL in ./.agentbox/sessions/ — grep it, diff it, commit it. It's yours, in your repo, offline by default.

Boring on purpose.

    
A flight recorder you can't audit would be a joke. AGENTBOX is ~1,000 lines of auditable Node built-ins — crypto, fs, child_process. No node_modules. No supply chain. No phone home. Ever.

    

      
// every event on the tape:
{ "i": 7, "t": 1727172000000,
  "type": "out",
  "data": { "kind": "tool",
            "text": "[TOOL] bash(...)" },
  "prev": "9f2c…",
  "hash": "e41b…" }

// hash = sha256(prev ‖ i ‖ t ‖ type ‖ data)
// edit anything → verify() fails at that index

      

        
Does it work with Claude Code / Cursor / OpenClaw?Yes — anything in a terminal can be wrapped. First-class MCP & Claude Code hooks are on the roadmap.

        
Isn't this just logging?Logs are text files. This is chain of custody: hash-linked, verifiable, classified, replayable, shareable.

        
Why not a SaaS dashboard?The answer to "can I trust my agent" shouldn't be "trust this vendor too." Your black box lives in your repo.

        
What does it cost?MIT, free forever. The receipt for this decision says "humans consulted: 2."
